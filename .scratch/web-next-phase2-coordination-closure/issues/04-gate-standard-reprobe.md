# 04: 资格门标准改写与同候选重探测

**What to build:** 资格门从"OS 隔离 + 网络出口收敛"改写为可强制的收口标准：平台强制层探针通过 + 六类写通道复核矩阵全部为拒绝 + 部署者书面接受残余风险。原因文本、重开条件与证据路径同步更新，界面显示"受限运行环境"及边界，不出现"已隔离"表述。探针与矩阵在同候选重跑并给出退出码。

**Blocked by:** 01、02、03

**Status:** ready-for-agent

- [ ] 门常量原因、重开条件与证据路径改写为新标准，仍为唯一事实来源、不可按请求翻转
- [ ] 行为探针覆盖：进程环境不含宿主凭据、agent home 在会话工作区内、工作目录作用域、网关越权负例、命令帧未授权负例
- [ ] 写通道矩阵六类通道复核全部为拒绝，矩阵文档更新并注明 L1 边界
- [ ] 残余风险接受文档记录范围、边界、责任与失效条件，等待用户签署
- [ ] web-next 协调入口文案改为"受限运行环境"，不再出现"已隔离"
- [ ] 三个 e2e 同候选重跑退出码 0（协调入口、重连配对、写通道探针）
- [ ] 门仍保持关闭：常量未翻转前任何入口返回 403 `coordination_gate_closed`
- [ ] 脱敏验收摘要入 `docs/acceptance/`，原始证据留 `.scratch/`
