# 03: Worker 命令帧授权校验（含恢复路径）

**What to build:** Worker 命令入口在执行前校验命令帧携带的服务端短期授权断言：签名有效、受众是本 Worker、命令类型在许可范围、任务/会话范围匹配、未过期。缺失或无效一律 fail-closed，不产生本地副作用并留审计；重启后的持久命令恢复路径同样校验，不能成为绕过手段。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 无授权断言的命令帧被拒，且无本地副作用（无进程、无文件写入、无工作区变更）
- [ ] 伪造签名、过期断言、受众非本 Worker 的命令帧被拒
- [ ] 来自已删除或已撤权主体的命令帧被拒
- [ ] 未知命令类型被拒（fail-closed）
- [ ] 恢复路径（重启后重放持久命令）同样校验，过期即拒绝
- [ ] 拒绝回执不泄露内部细节，且记录原因码
- [ ] 合法命令（工作区准备、会话轮次等）不受影响，现有 worker 测试全绿
- [ ] 负例测试与断言输出作为证据留存
