# 03: 跨 Runtime 执行闭环与结果回写

**What to build:** 现有有效 Runtime（pi / claude / opencode）各自通过合适入口完成同一流程：项目查询 → 交接 → 执行 → 报告，结果以引用形式回到协调上下文。至少一个 Runtime 用真实执行（本地或免费模型）跑通全链路，差异与未覆盖项如实记录。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 至少一个有效 Runtime 真实执行完成查询 → 交接 → 执行 → 报告，证据含命令与输出
- [ ] 同一流程在其余有效 Runtime 上以各自入口执行，差异（能力、入口形态、认证）明示
- [ ] 执行失败或取消在协调上下文可见并带原因
- [ ] 交接与启动过程留审计记录（主体、目标、revision、来源）
- [ ] 未覆盖项与限制如实标注，不冒充已覆盖
- [ ] 不调用付费模型；使用本地或免费模型
