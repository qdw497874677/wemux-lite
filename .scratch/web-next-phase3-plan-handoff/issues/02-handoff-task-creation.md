# 02: 协调到普通 Task 的交接与启动分离

**What to build:** 用户能把已批准计划交接成目标 Project 内的普通 Task：一次授权、幂等、原子的操作，Task 携带计划、验收标准与来源协调 Task/Session 引用；交接只创建不启动，启动是独立显式动作。执行结果与产物以引用形式回到协调上下文，协调讨论保持可用。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 交接创建普通 Task，携带计划引用、验收标准与来源引用，可在普通 Task 界面查看
- [ ] 重复交接请求（同 requestId）返回同一 Task，不重复创建
- [ ] 交接不自动启动：创建后无 Run，启动是独立操作
- [ ] 无权限（非成员、无目标 Project 访问权）交接被拒且不留半成品 Task
- [ ] 执行完成后协调上下文可见结果与产物引用，讨论继续可用
- [ ] Run 成功不自动 done，完成按审查策略显式提交
- [ ] 写通道矩阵新增"交接允许但受限"行，其余通道仍全拒绝
- [ ] 断言与截图作为证据留存
