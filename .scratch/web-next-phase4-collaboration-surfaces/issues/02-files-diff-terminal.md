# 02: 文件、Diff 与终端生命周期

**What to build:** 获权实施用户可浏览、修改会话工作区文件、查看 Diff、使用终端；终端支持创建、重连、关闭与资源清理；协调模式在任何路径都不取得实施写权。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 获权实施用户可浏览与修改文件并查看 Diff
- [ ] 终端可创建、重连、关闭；异常退出后无悬挂进程
- [ ] 协调模式无文件写入与终端能力（负例断言）
- [ ] 无权限用户无法读写工作区文件
- [ ] 文件写入与终端会话留有可复查记录
- [ ] 断言与截图作为证据留存
