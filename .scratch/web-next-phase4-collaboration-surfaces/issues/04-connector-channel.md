# 04: 连接器与渠道：配置、审批、投递与死信

**What to build:** 管理员可按授权配置连接器与渠道；Secret 写入不回显且不出现在日志、响应与事件；外部写需审批；投递与死信可查，支持幂等重试；撤权后立即停止投递。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 按授权配置连接器与渠道；未授权配置被拒
- [ ] Secret 写入后接口、界面、日志与事件均无明文
- [ ] 外部写入未获审批时不投递
- [ ] 投递记录与死信可查，含失败原因
- [ ] 死信幂等重试不产生重复外部副作用
- [ ] 撤权后未投递项立即失效，不再外发
- [ ] 连接器调用受能力令牌、allowedTools 与资源绑定约束
- [ ] 断言与截图作为证据留存
