# 02: 文件、Diff、终端与成果审查引用

Status: ready-for-agent
Blocked by: [01](01-canvas-fork.md)。

**Spec:** [会话协作界面](../spec.md)
**合并来源:** `43966aa` 的原票 02、03。
**What to build:** 获权实施用户可浏览修改文件、看 Diff、使用完整生命周期的终端，并阅读下载成果、以引用供审查使用。读取、写入与下载都受权限约束，协调模式始终没有实施写权。

## 文件、Diff 与终端

- [ ] 获权实施用户可浏览与修改文件并查看 Diff
- [ ] 终端可创建、重连、关闭；异常退出后无悬挂进程
- [ ] 协调模式无文件写入与终端能力（负例断言）
- [ ] 无权限用户无法读写工作区文件
- [ ] 文件写入与终端会话留有可复查记录
- [ ] 断言与截图作为证据留存

## 成果与审查引用

- [ ] 成果可阅读与下载，权限不足被拒
- [ ] 审查记录以引用方式指向成果，不复制现场内容
- [ ] 成果引用在执行会话被删除后仍可追溯（或明确标注失效）
- [ ] 断言与截图作为证据留存
