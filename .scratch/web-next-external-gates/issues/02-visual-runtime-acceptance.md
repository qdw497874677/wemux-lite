# 02: 独立视觉复审与真实运行时签收

Status: ready-for-human
Blocked by: 视觉复审需独立审查者；真实运行时验收需额外明确付费授权及[计划批准与交接](../../web-next-plan-handoff/issues/01-plan-approval-and-handoff.md)可用，不阻塞视觉复审的独立推进。

**Spec:** [外部服务与独立验收](../spec.md)
**合并来源:** `43966aa` 的原票 03、04。
**What to build:** 集中跟踪独立视觉复审与真实付费运行时签收，两组分别给结论。合并不代表授权使用付费模型；未授权时只准备步骤，付费项保持未完成，视觉复审仍可独立推进。

## 独立视觉复审

- [ ] 桌面视口复审完成
- [ ] 手机视口复审完成
- [ ] 问题清单区分阻塞与非阻塞，含截图与位置
- [ ] 阻塞问题登记处置结论（修复或责任票）
- [ ] 复审结论入库，摘要脱敏

## 真实付费运行时签收

- [ ] 真实付费运行时完成一次完整会话
- [ ] 完成一次计划批准与交接流程
- [ ] 记录模型、成本与配额影响
- [ ] 未授权或失败时如实标注未完成，不以本地模型结果替代
- [ ] 证据与结论入库，凭据不落明文

## 关闭条件

两组均由人工确认后关闭；任何一组未完成均不得作为[切根 go/no-go](../../web-next-cutover/issues/02-go-no-go-cutover.md)的已通过输入。
