# 01: 真实外部服务验收

Status: ready-for-human
Blocked by: OAuth/SMTP 无其他未完成票前置；渠道子项需[连接器/渠道实现](../../web-next-collaboration-surfaces/issues/03-connector-channel-acceptance.md)可用。真实凭据、外发对象与授权逐项确认，互不代替。

**Spec:** [外部服务与独立验收](../spec.md)
**合并来源:** `43966aa` 的原票 01、02。
**What to build:** 在一张人工验收票内覆盖真实 Google OAuth、SMTP 与外部渠道死信。两组验收分别记录前置条件、证据与结论，不能以其中一组通过代替另一组。Agent 只准备脚本与证据模板，不代用真实凭据执行。

## 执行计划

1. 准备真实 OAuth/SMTP 回调与邮件脚本，核对 PUBLIC_URL、半配置拒绝和敏感信息脱敏；密码找回只验证本地账号。
2. 渠道实现可用后确认测试对象，验证成功、明确失败和结果未知；无外部幂等支持的未知结果停止重试，人工核对。
3. 每个服务分别记录环境、候选、授权者和证据；任何子项未过保持未完成。

## 身份与邮件验收

- [ ] 真实 OAuth 完成注册与登录
- [ ] 真实 SMTP 收到验证邮件并完成链接流程
- [ ] 找回密码流程端到端可用
- [ ] 半配置（缺 client secret 等）时启动失败并给出明确原因
- [ ] 无邮件投递时返回 503 且界面有说明
- [ ] 邮件链接只由 `WEMUX_PUBLIC_URL` 拼接
- [ ] 截图与日志留档，凭据不落明文

## 外部渠道验收

- [ ] 真实渠道产生投递失败并进入死信，失败原因可见
- [ ] 稳定投递身份及支持的外部幂等键去重；不支持且结果未知时停止重试并人工核对
- [ ] 撤权后未投递项立即失效，不再外发
- [ ] 投递记录含身份与幂等键，可复查
- [ ] 日志与输出留档，脱敏入库

## 关闭条件

两组均由人工确认后关闭；任一未完成则保留对应未勾选项，不解除[切根 go/no-go](../../web-next-cutover/issues/02-go-no-go-cutover.md)的外部服务验收前置条件。
