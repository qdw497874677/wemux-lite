# 04: 协调入口人工签收与开门

Status: ready-for-human
Blocked by: [03](03-gate-standard-reprobe.md)。

**Spec:** [协调执行边界收口](../spec.md)
**合并来源:** `43966aa` 的原票 05（仅重编号）。
**What to build:** 部署者在目标宿主按 L1 新标准判定资格门，书面签署残余风险接受后才授权翻转门常量、开放受限协调入口，并重跑整票验收。选择 L1 或合并票据均不等于已签署风险接受。Agent 不代签、不自行开门；失败则保持关闭。

## 人工签收

- [ ] 部署者在目标宿主重跑探针与矩阵，退出码与断言输出留档
- [ ] 残余风险接受文档由用户签署（范围、边界、责任、失效条件）
- [ ] 门常量翻转后协调入口可用（可用性投影 + 入口 200），且普通项目 Task 写能力不受影响
- [ ] 至少一个有效 Runtime 上协调会话只读能力真实跑通
- [ ] 整票验收清单逐项勾选，NEXT-05 勾选为完成，计划批准与交接 ticket 的协调入口前置条件记录为满足
- [ ] 若任一探针失败：门保持关闭，NEXT-05 不勾选，缺口与责任票如实登记
- [ ] 验收摘要入库，原始证据留 `.scratch/`

通过后满足[计划批准与交接](../../web-next-plan-handoff/issues/01-plan-approval-and-handoff.md)的协调入口前置条件；不代表其他 spec/ticket 自动完成。
