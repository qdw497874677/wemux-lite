# 03: 资格门标准改写与同候选重探测

Status: ready-for-agent
Blocked by: [01](01-session-scoping-and-gateway-binding.md)、[02](02-command-frame-authorization.md)。

**Spec:** [协调执行边界收口](../spec.md)
**合并来源:** `43966aa` 的原票 04（仅重编号）。
**What to build:** 资格门从 OS 隔离与网络出口收敛改为平台强制层探针、平台中介的六类写通道拒绝证据及部署者书面残余风险接受。同步原因、重开条件、证据路径及“受限运行环境”文案，同候选重跑并给出退出码。L1 不能证明宿主文件不可读或进程无法直接外联。

## 验收

- [ ] 门常量原因、重开条件与证据路径改写为新标准，仍为唯一事实来源、不可按请求翻转
- [ ] 行为探针覆盖：进程环境不含宿主凭据、agent home 在会话工作区内、工作目录作用域、网关越权负例、命令帧未授权负例
- [ ] 写通道矩阵六类通道复核全部为拒绝，矩阵文档更新并注明 L1 边界
- [ ] 残余风险接受文档记录范围、边界、责任与失效条件，等待用户签署
- [ ] web-next 协调入口文案改为"受限运行环境"，不再出现"已隔离"
- [ ] 三个 e2e 同候选重跑退出码 0（协调入口、重连配对、写通道探针）
- [ ] 门仍保持关闭：常量未翻转前任何入口返回 403 `coordination_gate_closed`
- [ ] 脱敏验收摘要入 `docs/acceptance/`，原始证据留 `.scratch/`

本票完成只代表证据准备完成；签署风险接受、开门与 NEXT-05 整票关闭仍由 [04](04-coordination-acceptance.md) 独立控制。
