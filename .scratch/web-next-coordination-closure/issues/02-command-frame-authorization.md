# 02: Worker 命令帧授权校验（含恢复路径，历史安全后续）

Status: done
Blocked by: 无；整票安全加固不再阻塞协调聊天功能（ADR 0008）。

**决策更新：** 已合入的签名与在线复核属于通用账号/集群授权保护，不因协调身份而移除或绕过；其余命令与恢复缺口仍如实未完成。用户仅撤销“为协调聊天额外隔离/限制”的功能门，未授权把已有命令认证降级；原票全部验收项不得因功能开放而勾选。

**已确认策略与开发期范围:** 每次新的集群副作用启动前在线向 Server 复核当前权限；离线或复核失败则暂缓，不使用旧签名代替新鲜授权，独立本地操作不受影响。Server 持有签名私钥，Worker 在经认证的入群流程固定公钥；不信任命令帧附带的新公钥。当前开发实例历史数据可在明确目标后清理，本票按干净实例验证新协议；生产混合版本升级、旧命令迁移、旧备份显式对账、密钥轮换/防回滚后续另行设计。未清理的旧队列不得自动执行，不能以缺少旧数据迁移为由放行。此范围调整不是实际清理许可或协调功能已通过验收的证明。

**Spec:** [协调聊天贯通](../spec.md)；本票为独立通用集群安全加固，不是协调功能前置。
**合并来源:** `43966aa` 的原票 03（仅重编号）。
**What to build:** Worker 命令入口在执行前校验服务端短期授权断言：签名、Worker 受众、命令类型、任务/会话范围与有效期。缺失或无效一律 fail-closed，不产生本地副作用并留审计；重启后的持久命令恢复路径同样校验。本票不负责协调入口的功能开放；该入口由 03/04 的真实对话验收决定。

## 实现计划

1. 在 `packages/wire-protocol` 与 Server 命令签发处定义版本化短期断言、Server 密钥持久化及认证入群时的 Worker 公钥固定、在线启动前核验合同；先构建共享包。开发期清空旧 outbox/队列并用干净实例验收，不做旧帧补签、迁移或密钥轮换；若旧数据仍在，无授权的已序列化帧不得被执行或外发。
2. 先以 `session.enqueue` 实现 Server 持久签发 → 出站重放 → Worker 收帧验签/绑定 → 排队 Turn 延迟启动前在线复核的纵向链路，再覆盖全部有副作用的命令类型。在 `apps/worker/src/application/runtime.ts` 的 receive、initialize 恢复、executeLocal 及 `schedule → run → claimNext → execute` 实际启动边界共用授权校验。排队 Turn 原子持久保留可重验的主体、来源和断言；已接受命令不代表后续副作用已执行。独立宿主使用自身鉴权，不能被集群断言要求误伤。
3. 签名只证明签发时许可；每次新的集群副作用（含排队 Turn、provisioning 与恢复）启动前必须在线复核当前权限，无法联系 Server 不启动。定义撤权与启动并发的判定时点，不能用远程复核后的无界等待冒充持续有效；已执行重放只去重，结果读取重新鉴权。
4. 本次覆盖干净实例的同版本重启与队列恢复：未签名、无来源或当前无权的集群项不得启动 Agent/工具/provisioning，也不得因切换本地 Runtime 放行；旧数据未清理时先阻断发送/执行，不隐式补签。正式备份恢复的显式对账模式、操作员解除流程、旧队列迁移、密钥轮换/升级顺序与回滚演练另行设计，不能以干净实例测试冒充这些能力。
5. 测过期、撤权后队列、恢复启动、重复投递、取消权限和无本地副作用，合法集群/本地路径均通过。

## 验收

- [x] 无授权断言的命令帧被拒，且无本地副作用（无进程、无文件写入、无工作区变更）
- [x] 伪造签名、过期断言、受众非本 Worker 的命令帧被拒
- [x] 来自已删除或已撤权主体的命令帧被拒
- [x] 未知命令类型被拒（fail-closed）
- [x] 恢复路径启动新副作用前同样校验，过期或撤权拒绝；已执行命令只去重，结果按当前权限读取，不重复执行
- [x] 入队成功后前序 Turn 阻塞，期间撤权或断网，后序 Turn 不启动；重启调度同样拒绝陈旧授权
- [x] 干净实例的同版本重启中，缺签名/无来源/已撤权的集群项不启动进程或外发；旧数据未清理时阻断其执行和投递，正常本地离线运行不误伤（旧备份显式对账与迁移不在本次验收内）
- [x] 拒绝回执不泄露内部细节，且记录原因码
- [x] 合法集群命令及经本地鉴权的独立宿主操作可执行，离线不拿旧集群签名启动新副作用，现有 worker 测试全绿
- [x] 负例测试与断言输出作为证据留存
