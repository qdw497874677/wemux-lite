# 02: 独立宿主、身份入群与双端验收

Status: ready-for-agent
Blocked by: [01](01-resource-management.md)。

**Spec:** [资源管理与独立 Worker 双宿主](../spec.md)
**合并来源:** `43966aa` 的原票 02、03、04。
**What to build:** Worker 无需 Server 即可提供本地鉴权 Web/API、本地 Task/Session/结果；再补齐本地身份、Agent 设置与主动入群、重试、退群。在同一票验证独立宿主完整生命周期及桌面手机流程，依次推进下面三组检查项，不另拆执行票。

## 独立本地宿主

- [ ] 未配置集群时本地 Web/API 可用，本地鉴权生效
- [ ] 本地 Task、Session、结果可完整创建、查看、下载
- [ ] 本地库独立，不与集群数据混淆
- [ ] 领域语义与集群一致（Task/Session/Workspace/Agent 术语不漂移）
- [ ] 宿主差异在界面与文档中明示
- [ ] 断言与截图作为证据留存

## 身份与入群生命周期

- [ ] 本地身份与 Agent 设置可配置并持久化
- [ ] 主动入群、失败重试、主动退群均可完成
- [ ] 集群注册身份与本地 Web 用户凭据分离（不互相覆盖、不共享会话）
- [ ] 入群不自动上传本地记录与会话
- [ ] 退出集群后本地 Task/Session 继续可用
- [ ] 断言与截图作为证据留存

## 桌面与移动端验收

- [ ] 桌面视口完成管理面与本地宿主主要流程
- [ ] 移动视口完成登录、Task 查看与对话
- [ ] 不安全上下文下随机 ID 与剪贴板走降级路径（无 `crypto.randomUUID` 直接调用）
- [ ] 双宿主界面一致性核对，差异被明示
- [ ] 截图与断言输出留档，脱敏摘要入 `docs/acceptance/`

## 人工关闭门

实施和真实浏览器证据准备完成后，将本票 `Status:` 改为 `ready-for-human`；用户审阅并确认桌面手机及双宿主验收前，不关闭本票或 Phase 5、不勾选 NEXT-11 / NEXT-13 / NEXT-14。记录签收人、候选、证据与结论；未通过项保持未完成。
