# 02: 独立宿主、身份入群与双端验收

Status: ready-for-agent
Blocked by: 入群生命周期与最终验收依赖 [01 资源管理](01-resource-management.md)；独立本地宿主可基于已有 Task Session 和 Run/审查合同先行实施。

**Spec:** [资源管理与独立 Worker 双宿主](../spec.md)
**合并来源:** `43966aa` 的原票 02、03、04。
**What to build:** Worker 无需 Server 即可提供本地鉴权 Web/API、本地 Task/Session/结果；再补齐本地身份、Agent 设置与主动入群、重试、退群。在同一票验证独立宿主完整生命周期及桌面手机流程，依次推进下面三组检查项，不另拆执行票。

## 实现计划

1. 复用 `apps/worker/src/local-control` 和 local-workbench 已有鉴权/Session/入退群基础，补同领域 schema 的本地 Task 与持久关联，不从零重建宿主。
2. 转换 createSession 调用方，以宿主端口共用运行时及 web-next 界面，保留本地库和集群身份分离。
3. 测无 Server、入群失败重试、已入群、主动退群与重启；本地记录不自动上传，本地和集群并发准入交派发票联合验证。
4. 明确显式公网 HTTPS 部署合同：公开地址、受信任代理/TLS 边界、认证 Cookie 与流式连接；复用既有 HTTP 服务，不预选新 TLS 框架。真实域名/证书/暴露范围须部署者单独授权。
5. 真浏览器跑桌面手机登录、Task/Session/成果及身份设置，覆盖 HTTPS 流式连接重连及 HTTP 降级路径后转人工签收。

## 独立本地宿主

- [ ] 未配置集群时本地 Web/API 可用，本地鉴权生效
- [ ] 本地 Task、Session、结果可完整创建、查看、下载
- [ ] 本地库独立，不与集群数据混淆
- [ ] 领域语义与集群一致（Task/Session/Workspace/Agent 术语不漂移）
- [ ] 宿主差异在界面与文档中明示
- [ ] 断言与截图作为证据留存

## 身份与入群生命周期

- [ ] 本地身份与 Agent 设置可配置并持久化
- [ ] 主动入群、失败重试、主动退群均可完成
- [ ] 集群注册身份与本地 Web 用户凭据分离（不互相覆盖、不共享会话）
- [ ] 入群不自动上传本地记录与会话
- [ ] 退出集群后本地 Task/Session 继续可用
- [ ] 断言与截图作为证据留存

## 公网 HTTPS 验收

- [ ] 显式配置公开 HTTPS 地址与部署边界，无隐式暴露；错误配置安全失败
- [ ] 在获授权的真实 HTTPS 环境验证登录、会话保护、API、流式连接与重连，证书/代理配置不泄凭据
- [ ] 未取得域名/证书及部署授权时该分项保持未完成，不用 localhost 或 HTTP 截图代替

## 桌面与移动端验收

- [ ] 桌面视口完成管理面与本地宿主主要流程
- [ ] 移动视口完成登录、Task 查看与对话
- [ ] 不安全上下文下随机 ID 与剪贴板走降级路径（无 `crypto.randomUUID` 直接调用）
- [ ] 双宿主界面一致性核对，差异被明示
- [ ] 截图与断言输出留档，脱敏摘要入 `docs/acceptance/`

## 人工关闭门

实施和真实浏览器证据准备完成后，将本票 `Status:` 改为 `ready-for-human`；用户审阅并确认桌面手机及双宿主验收前，不关闭本票、不认定双宿主 spec 验收通过、不勾选 NEXT-11 / NEXT-13 / NEXT-14。记录签收人、候选、证据与结论；未通过项保持未完成。
