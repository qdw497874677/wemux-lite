## 旁路勘察

- [ ] 列出全部无 Task 兼容入口与调用方，含路径、调用场景与是否仍在被使用

- [ ] 报告区分已实现、已验证与未完成，含可复查证据
- [ ] 不修改产品行为，仅勘察

## 操作级登记表

- [ ] 每行落到操作级（入口、角色、权限、证据、状态）
- [ ] 状态明确区分已实现、已验证、未完成
- [ ] 每项已验证条目附可复查证据路径或断言输出
- [ ] 未完成项登记为缺口与责任票
- [ ] 登记表入库（脱敏），原始证据留 `.scratch/`
