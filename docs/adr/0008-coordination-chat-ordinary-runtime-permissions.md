# 协调聊天使用普通 Runtime 权限，隔离另行交付

用户确认平台协调聊天与普通 Pi Agent 对话一样，不为协调身份额外限制读文件、改代码或联网；如需隔离，后续独立设计和交付。此决定取代 [ADR 0007](0007-task-bound-conversation-direction.md) 中“协调讨论强制只读、禁止任意 Shell，无法强制约束即关闭入口”的部分，以及原协调资格门对 OS 隔离、L1 收口与书面残余风险接受的开门前置。原因是这些额外约束妨碍正常 Agent 对话，且不能实际证明进程隔离；不再为开放功能制造虚假的安全保证。

不变：Session 必须绑定 Team 级协调 Task，用户须有 Team/Worker/Workspace 权限，平台 API 仍按实际获权 Project/Task 逐项校验，普通账号鉴权、命令/工具的既有授权与审批不因协调身份绕过。协调 Task 并非实施 Task，创建普通 Task、派发和交接仍遵守各自权限与明确操作合同；Agent 能操作文件不表示自动完成、取消或批准普通 Task。入口以真实创建、发送、恢复、Web 可用性及权限负例验收，不以风险接受或隔离探针为前置。既有部分安全加固保留为防止伪造集群命令/跨身份越权的通用工作，不作为协调入口特有开门门槛。历史 FAIL 与验收报告保持历史事实，不回写为当时 PASS。
